Where do Asset Keys come from?

Открой Discord Developer Portal → твоё приложение → Rich Presence → Art Assets. Значение Key должно совпадать с именем загруженного изображения.

How rotation works

После включения программа будет автоматически выбирать случайный Presence из Presence List через случайный интервал.

Presence Rotation

Автоматически менять Presence через случайный интервал.

sec
Минимальная задержка между сменами.
sec
Максимальная задержка между сменами.
! Для работы Rotation должен содержать хотя бы один Presence в Presence List.

Application Settings

Управление конфигурациями Rich Presence.

Configuration Profiles

Сохраняйте несколько наборов Rich Presence и переключайтесь между ними.

Например: Gaming, Work, Development, Config или Test.

Configuration Files

Экспортируйте конфигурацию в JSON или импортируйте её с другого компьютера.

ExportСохранить текущую конфигурацию в JSON-файл.
ImportЗагрузить конфигурацию из JSON-файла.
Импорт заменит текущую активную конфигурацию. Сохранённые профили при этом не изменяются.
